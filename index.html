安装教程

如何安装 Legendary Gods

按照以下步骤，几分钟内即可开始游玩。

1

准备运行环境

确保你已安装 Java 17（推荐 Eclipse Temurin 或 Oracle JDK）。整合包基于 Minecraft 1.20.1 Forge，请确认启动器支持该版本。

2

选择启动器并分配内存

推荐使用 FCL / ZL2 / PCL2 启动器，分配至少 4GB 内存，建议 6GB 以上以获得更流畅的体验。

3

导入整合包

从作者 B站视频评论区或指定渠道获取整合包文件（通常为 .zip 格式）。在启动器中选择“导入整合包”，选中下载的文件，等待自动完成安装。

4

启动游戏

安装完成后，在启动器版本列表中选择 Legendary Gods，点击启动。首次加载可能需要较长时间，请耐心等待。

5

开始游玩

进入游戏后，建议先查看任务书了解整合包引导内容。熟悉战斗操作后，尝试挑战 NOOP、使用蓝恶魔三叉戟与 woopie，体验完整的烦村战斗节奏。
